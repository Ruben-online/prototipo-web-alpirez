Esta carpeta está reservada para el desarrollo del backend del proyecto.

## Responsabilidades

El equipo de backend será responsable de:

- Implementar la API.
- Configurar la base de datos.
- Implementar la autenticación y autorización.
- Gestionar pacientes, consultas y citas.
- Validar los datos recibidos.
- Definir y documentar los endpoints.
- Configurar las variables de entorno del servidor.
